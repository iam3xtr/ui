# @iam3xtr/ui

Visual foundation for 3xtr.im applications.

Owns design tokens, CSS/SCSS themes, and shared visual assets such as the logo and loader SVGs. It does not own Vue components, application state, routing, API clients, or domain logic.

The package is prepared for private GitHub Packages publication. Its current
root entry is deliberately empty: Task A11.2 adds the documented tokens, theme,
SCSS and asset exports. It must not gain Vue, application state, routing, API
clients or domain logic.
